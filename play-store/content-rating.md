# Content rating (IARC anketasi) — taklif etilgan javoblar

Kategoriya: **Utility, Productivity, Communication, or Other** (Yordamchi ilova)

| Savol | Javob |
|---|---|
| Zo'ravonlik | Yo'q |
| Jinsiy kontent / yalang'ochlik | Yo'q |
| Qo'pol so'zlar | Yo'q |
| Nazorat qilinadigan moddalar (alkogol, tamaki, giyohvand) | Yo'q |
| Qimor | Yo'q |
| Foydalanuvchilar o'rtasida muloqot | **Ha** (mijoz ↔ mutaxassis chat va qo'ng'iroq) |
| Foydalanuvchi yaratgan kontent almashinuvi | **Ha** (chat, fayl) |
| Joylashuvni boshqalar bilan ulashish | Yo'q |
| Raqamli xaridlar | **Ha** (tarif/xizmat to'lovi) |
| AI yaratgan kontent | **Ha** (AI yuridik yordamchi) |

Kutilgan reyting: odatda **3+/Everyone 10+** (muloqot va xaridlar sababli). Yakuniy reytingni IARC anketasi beradi.
